Online resources are messy, and many bundled software, modified and cracked versions contain hidden Trojans, which can easily lead to privacy leaks and account theft. ## Introduction to mainstream remote control tools
### 1. ToDesk
A popular domestic remote tool, free for personal non-commercial use, with stable connection speed, end-to-end encryption, supports Windows / macOS / Linux / Android / iOS, supports file transfer, multiple monitors, privacy screen, and black screen mode. It is very suitable for helping people repair computers and working from home.
👉 Obtain: [Go to ToDesk official website to download ](https://todesk.com/)

### 2. Sunflower remote control (Oray)
The old domestic remote control has a complete ecosystem and can be used with a boot stick to achieve remote booting; it supports remote desktop, camera viewing, SSH, and port mapping. The free version has traffic limits, and there are paid enterprise plans. Suitable for operation and maintenance and remote management of home hosts.
👉 Obtain: [Go to Sunflower official website to download ](https://sunlogin.oray.com/)

### 3. NetEase UU Remote
The remote tool produced by NetEase is free of charge and has no ads. It features ultra-low latency, supports 4K/144 frame transmission, supports Windows / macOS / Android / iOS / TV, supports high-speed file transfer, remote boot, privacy screen, and controller peripheral mapping. It is suitable for remote gaming and office assistance. 👉 Obtain: [Go to UU Remote official website to download ](https://uuyc.163.com/)

### 4. RustDesk (open source and free)
Completely open source, self-hosted optional remote desktop software, there is no mandatory cloud, you can build your own relay server, and your privacy is controllable. Cross-platform support for Windows, Mac, Linux, and Android, suitable for technology enthusiasts and programmers.
👉 Get: [Go to RustDesk GitHub / official website](https://rustdesk.com/zh-cn/)

### 5. AnyViewer
A lightweight domestic remote tool, the free version has many open functions, simple connection, low latency, and is suitable for novices. It also supports cross-platform remote access and unattended access.
👉 Obtain: [Go to AnyViewer official website](https://www.anyviewer.com/)

### 6. TeamViewer
International long-established remote control software, **free for personal non-commercial use**, enterprise use requires a license. Note: Its commercial testing is relatively strict, and frequent connections can easily be judged as commercial use and restricted.
👉 Obtain: [Go to TeamViewer official website](https://www.teamviewer.com/)

### 7. AskLink
Cross-platform remote tool. The free version has no session limit and comes with 50 hours of high-speed line per month. It supports Windows / macOS / Linux / Android / iOS. It supports file transfer, clipboard synchronization, privacy screen, and multi-device screen wall. It is suitable for batch operation and maintenance of multiple devices and remote office assistance. 👉 Obtain: [Go to AskLink official website](https://www.asklink.com/)

## How to choose? Quick selection reference
- Ordinary users, helping family members repair computers: ToDesk / AnyViewer
- Requires remote startup, industrial control, long-term operation and maintenance: Sunflower
- Value privacy, want to build your own server, and like open source: RustDesk
- Overseas cross-regional connection: TeamViewer

## Recommendations for safe use of remote tools
1. **Only download from the official website**, reject installation packages shared by third-party sites, network disks, and public accounts to avoid bundling Trojans.
2. Set a strong access password, and conditionally enable two-step verification and device whitelisting.
3. Exit the client promptly when not in use and turn off unattended access.
4. Try to avoid remotely operating sensitive pages such as bank cards and passwords under public networks.
5. Do not use remote control tools for monitoring, secret photography, data theft and other illegal activities.
