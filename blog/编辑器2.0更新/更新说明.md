## 新增功能

### 1. 媒体能力扩展

| 类型 | 语法 | 表现 |
| --- | --- | --- |
| 视频 | `![说明](clip.mp4 "封面.jpg")` | 圆角容器、时长角标、点开全屏 |
| 动图 | `@motion[说明](loop.mp4)` | 无声循环、滚出视口自动暂停 |
| GIF | `![说明](anim.gif)` | GIF 角标，不套缩略图 |
| 音频 | `@audio[标题](voice.mp3)` | 独立卡片，含标题与来源标签 |

媒体统一装入 `.md-media` 容器，配角标与图注；视频不查 WebP 缩略图映射，避免 GIF 静止、视频打不开。

### 2. 内容块类型扩容

新增 7 种块类型，前台与编辑器共用同一套解析规则：

- `@link[标题](url "描述")` — 链接卡片，按域名色相染色
- `@embed[标题](url)` — 视频嵌入，B 站 / YouTube / Vimeo 自动转播放器
- `@file[名称](manual.pdf)` — 附件下载卡
- `@gallery[a.jpg, b.jpg, c.jpg]` — 2~4 列图集
- `> [!NOTE/TIP/IMPORTANT/WARNING/CAUTION]` — GitHub 提示块
- `- [ ]` / `- [x]` — 待办清单
- `|l` / `|c` / `|r` — 段落左 / 中 / 右对齐

### 3. 建模工具

- 媒体库四档筛选（图片 / GIF / 视频 / 音频），首帧抓取、时长与类型角标
- 拖拽上传、剪贴板直传
- 插入面板统一入口，共 15 项

### 4. 预览体系

「看效果」面板内嵌 iframe 实时渲染，支持设备宽度切换、重新渲染、新窗口打开，快捷键 `Ctrl + Shift + P`。

## 界面与体验

- **视觉统一**：与主站共用同一套 CSS 变量、玻璃浮层导航、彩虹描边主按钮。
- **响应式重构**：1020px 以下切换为单列布局 + 吸顶分栏（正文 / 素材 / 设置）+ 底部固定操作条；输入框字号 16px 规避 iOS 自动缩放；适配 `env(safe-area-inset-bottom)`。
- **双语体系**：`data-t`（文本）、`data-th`（富文本）、`data-tp`（占位符）、`data-tt`（提示气泡）四类标注，与主站共享 `jy-lang`。
- **工具栏重排**：对齐操作（左 / 中 / 右）由「插入」类目迁至文字格式组，符合操作语义。
- **移动端预览**：宽度 ≤ 760px 时隐藏无意义的设备切换按钮，改为「手机视图 · 实际宽度」状态标识。
- **正文阅读增强**：图片 / GIF / 视频支持点击放大、原尺寸拖动查看、左右翻页；单张时自动隐藏翻页箭头。

## 缺陷修复

| # | 症状 | 根因 | 处理 |
| --- | --- | --- | --- |
| 1 | 点「预览」或「看效果」整页卡死 | `mdToHTML` 主循环空转：某行命中块起始正则但无分支消费，游标 `i` 不前进 | 兜底强制前进 + 宽容正则 + `4 × 行数` 熔断上限 |
| 2 | 桌面 → 平板 → 手机切换硬切，反向顺滑 | 同时动画 `width` 与 `max-width`，`min()` 被单侧夹取 | 统一换算为 px，单属性插值 |
| 3 | 动图点击后被暂停 | 残留 `.paused` 蒙层与点击委托 | 移除暂停语义，改为放大查看 |
| 4 | 正文图片 / 视频无法放大 | 灯箱仅服务于相册 | 新增媒体收集器，复用灯箱 |
| 5 | 待办事项无法勾选 | 渲染写死 `disabled` + CSS `pointer-events: none` | 解除锁定；前台本地记忆，编辑器写回正文 |
| 6 | 「💾 保存到本地」点击无响应 | `#saveBtn` 从未绑定事件 | 补绑监听 + 权限预校验 + 失败可见提示 |
| 7 | 媒体库出现重复条目 | 三处并发调用刷新，数组重复 push | Promise 串行队列 |
| 8 | 音频进度条无法拖动 | 服务端未返回 `Accept-Ranges`，`seekable` 恒为 `0 ~ 0` | 检测退化后转 Blob URL，恢复可寻址 |
| 9 | 手机端设备切换无变化 | 目标宽度被面板可用宽度 `Math.min` 夹取，三档同为 358px | 窄屏隐藏切换器，预览铺满 |

**附带修复**

- 两处 `data-t` 属性内含 HTML 标签，经 `textContent` 写入后文案被截断，改用 `data-th`
- 底部操作条 6 个按钮在英文界面缺失 `title` 提示
- 语言切换后媒体库计数翻倍（同 #7）

## 兼容性与性能

- **安全策略**：链接仅放行 `http(s)` 与 `mailto`，非法地址退化为纯文本，不生成可点击外壳。
- **懒加载**：动图使用 `IntersectionObserver`，仅在视口内播放。
- **布局稳定**：读取真实媒体尺寸回填 `aspect-ratio`，消除加载期位移。
- **流量控制**：仅在检测到媒体**不可寻址**时才整包转 Blob（音频 ≤ 12 MB 自动预修、视频 ≤ 80 MB 按需），`saveData` 模式下完全跳过。
- **降级路径**：视频 404 时显示可读提示；头图视频失败自动撤除并露出渐变兜底。

## 已知限制

1. 媒体可拖动依赖客户端 Blob 兜底；根治仍需服务端返回 `Accept-Ranges: bytes`。
2. 待办勾选在前台存于浏览器本地（`localStorage`），不写入 `index.md`；仅编辑器内勾选才同步正文。
3. 单篇文章媒体总量过大时，首次预览渲染耗时随文件数线性增长。
