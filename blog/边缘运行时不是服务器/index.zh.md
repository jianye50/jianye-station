第一次把 Worker 部署上线的时候，我盯着那个 `*.workers.dev` 的域名看了半天，总觉得少了点什么。后来想明白了：少了「机器」。没有 SSH，没有 `systemctl`，没有 `/var/log`，也没有凌晨三点因为内存涨到 95% 而被 OOM 杀掉的那个进程。

它就这么跑着，一分钱不花，每天十万次请求的额度用不完。

## 一、它到底是个什么东西

官方的说法是「在边缘节点执行的 JavaScript」。这句话容易让人误会成「小型服务器」，但它不是。更准确的说法是：**一个函数，请求来了就执行，返回了就结束。**

这带来三条硬边界，写代码之前必须先认：

1. **没有文件系统。** 写进去的东西下次读不到。要存东西，得用 KV、D1、R2 或者外面自己的数据库。
2. **没有常驻进程。** 定时任务是有的，但最细到分钟级；想「每五秒检查一次设备状态」这种活，它干不了。
3. **CPU 时间是硬上限。** 免费版单次请求 10 毫秒，付费版 30 秒。注意是 CPU 时间，不是等待时间——发一个 HTTP 请求等两秒不算，但那两秒里你不能算哈希。

再加一条容易被忽略的：**默认进不了你的内网**。它能往外发请求，但你的 NAS、你的路由器、你家里那台跑着 Home Assistant 的小主机，它都看不见。

```toml
# wrangler.toml —— 一个 Worker 的全部「机器配置」
name = "file-list"
main = "src/index.ts"
compatibility_date = "2026-10-01"

[[d1_databases]]
binding = "DB"
database_name = "openlist"
database_id = "xxxxxxxx"
```

就这么几行，没有 Dockerfile，没有 Nginx，没有证书续期。

## 二、什么样的活适合放上去

判断标准其实只有一句话：**这个程序是不是「请求进来 → 拿数据 → 返回」？**

是的话，基本都能搬。比如：

- **文件列表 / 网盘聚合**。OpenList 的 TypeScript 版就是这么干的：文件本身在阿里云盘、OneDrive、S3 里，程序自己只负责「问一下有什么、把链接给我」。数据不在它手上，它就不需要硬盘。
- **API 网关 / 反代 / 鉴权**。进来验个 JWT，转发给上游，回来的 JSON 加工一下。
- **Webhook 中转**。GitHub 推一下，它转给 Telegram。
- **短链、图床索引、静态站的小接口**。

这些程序的共同点：**它们没有「自己的状态」**。状态全在别人那儿，自己只是中间那层薄薄的胶水。

## 三、什么样的活搬不上去

反过来，只要程序需要「一直醒着」，就别想了。

| 能力 | OpenList-Worker | Home Assistant |
| --- | --- | --- |
| 数据在哪 | 远端网盘，走 HTTP 拿 | 本地设备，走局域网直连 |
| 需要常驻 | 不需要，请求来了才动 | 必须，7×24 事件循环 |
| 要接硬件 | 不需要 | Zigbee、蓝牙、USB 网关 |
| 状态存哪 | D1 / KV，随时可丢 | 本地 SQLite，高频写入 |
| 搬上边缘的后果 | 更省钱、更快 | 拔掉所有设备，彻底失能 |

Home Assistant 是个特别好的反例。它的全部价值建立在「它和你家的灯在同一个网段」这件事上——设备状态一变，它得立刻知道；你按一下开关，它得立刻发指令。把它搬到离你家两千公里的机房，它连不上任何一个设备，剩下的只有一个空壳网页。

所以后来我做的事是反过来的：**大脑留在壁橱里，边缘只做手脚。** Home Assistant 跑在家里那台旧笔记本上，用 Cloudflare Tunnel 穿出去；Worker 只在旁边打杂——收 webhook、发通知、做一层鉴权。真要远程看一眼客厅的灯，走的是隧道，不是把家搬走。

## 四、我现在的判断顺序

遇到一个新项目，我会按这个顺序问自己：

1. 它的数据在不在自己手上？在 → 先别搬。
2. 它需不需要秒级地「主动」做点什么？需要 → 先别搬。
3. 它要不要连局域网里的东西？要 → 先别搬。
4. 上面三条都否 → 那它大概率可以在边缘跑得很开心。

三个问题问完，能过的项目其实比想象中多。过去两年我搬上去的东西——图床索引、短链、几个 webhook 中转、一个 RSS 清洗服务——加起来省掉了一台 VPS 和它带来的所有运维。

但那些「一直醒着」的东西，一台都没动。它们还在壁橱里，风扇有点响，两个月重启一次，挺好的。
