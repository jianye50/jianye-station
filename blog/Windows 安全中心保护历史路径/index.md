```
C:\ProgramData\Microsoft\Windows Defender\Scans\History
```

将此文件夹内可以删除的文件删除，不可以的跳过

在安全中心保护运行中，此文件夹将进行保护，您可以使用安全中心管理工具关闭后查看

需要关闭安全中心或进入安全模式或者 PE，因为文件夹可能没有权限

此路径为系统受保护路径，会被隐藏如果没有就跳转前一个目录
