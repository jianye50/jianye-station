```
C:\ProgramData\Microsoft\Windows Defender\Scans\History
```

Delete files that can be deleted in this folder and skip files that cannot be deleted.

While Security Center protection is running, this folder will be protected and you can view it after closing it using the Security Center management tool.

You need to close the security center or enter safe mode or PE because the folder may not have permissions

This path is a system protected path and will be hidden. If not, jump to the previous directory.
