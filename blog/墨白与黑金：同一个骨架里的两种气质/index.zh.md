这个站现在有两个地址：

- **墨白版**：http://jianye.pages.dev/mono

@link[墨白版](http://jianye.pages.dev/mono)
- **黑金版**：http://jianye.pages.dev/gold

@link[黑金版](http://jianye.pages.dev/gold)

它们不是两个网站。同一套 HTML、同一份脚本、同一批文章与照片，路由、播放器、灯箱、双语切换全都一模一样。唯一的差别，是颜色。

听起来像换肤这种小事，但做完之后我发现，颜色的选择其实决定了一件事：**这个站想让访客先看见什么。**

---

## 先立骨架，再谈颜色

在动颜色之前，这两版共享一套很硬的规矩，也正是这套规矩让"换颜色"变得有意义：

- **圆角收成 2px**。满屏的圆角胶囊是 2019 年的语言，现在看着像塑料。
- **投影全部清零**。层级不靠浮起来表达，靠发丝线（1px、透明度 10% 左右）和留白。
- **标题用宋体**，正文用无衬线。中文的宋体有笔锋，放大之后自带一种"被排版过"的庄重感。
- **照片默认去色**，鼠标指到哪张，哪张慢慢回色。
- **编号代替图标堆砌**。项目卡上是 01、02、03，不是一堆彩色小方块。

这些定完，页面其实已经站住了。剩下的颜色，只是给它挑一个气口。

---

## 墨白：把颜色退到只剩层次

墨白版的底色是 `#08080a`，文字是 `#f5f2ec`。

都不是纯色。纯黑 `#000` 在屏幕上像一块洞，纯白 `#fff` 又刺眼；稍微偏一点，才有"物"的感觉——像宣纸，像还没上机的新闻纸。

这一版的设计逻辑是**编辑设计**（editorial design）：没有颜色可用，层级就只能靠字号对比、字距、行高、留白和线条来建立。所以它看起来像一本排版认真过的册子：标题大而疏，正文窄栏、行距 2.1 倍，章节之间用一条细线断开。

全站彩色只允许出现在两个地方：照片悬停时的原色，和灯箱里点开的那张大图。

> 墨白版的野心是"消失"。访客不应该注意到设计，只应该注意到你写了什么、拍了什么。

它的优点和缺点其实是同一件事：**太安静了**。安静到像一个 Markdown 渲染器，安静到有点不像"个人主页"，更像一份打印出来的作品集。

---

## 黑金：给状态一盏灯

黑金版要解决的正是这个问题：怎么在不破坏克制的前提下，让页面有一点"在场感"。

第一步是换底。底色从冷墨黑 `#08080a` 换成带一点褐的暖墨黑 `#0a0907`——这一点点暖意很关键，冷黑配金会显脏，暖黑配金才像老器物。

第二步是定金的用法。这里我守了一条线：

**金只出现在"状态"上，从不出现在"装饰"上。**

具体说，金只负责四件事：

1. **你在哪**——当前页签是金色文字，底下一条金色细线，带一圈很淡的光晕
2. **什么能点**——正文链接、次要按钮、hover 态
3. **进度到哪**——阅读进度条、播放器进度环
4. **起点在哪**——Logo 那个小圆点、启动屏上的金线

除此之外的地方，一概不金。项目卡的背景、照片、正文、页脚大片区域，仍然是墨黑与象牙白。

金色本身也分了两档：`#c9a45c` 是偏古铜的哑光金，大面积用不刺眼；`#e8cf96` 更亮，只给悬停和当前态提亮一瞬。这个层次很重要——只有一种金，页面会显得平；金太亮，又会变成 KTV 包厢。

> 如果墨白版是一本册子，黑金版就是这册子摆在射灯下的样子。内容没变，光变了。

## 对照

| | 墨白（mono） | 黑金（gold） |
|---|---|---|
| 底色 | 冷墨黑 `#08080a` | 暖墨黑 `#0a0907` |
| 强调色 | 无（象牙白承担一切） | 古铜金 `#c9a45c` / `#e8cf96` |
| 彩色出现处 | 只有照片与灯箱原图 | 照片，加上所有"状态" |
| 气质 | 纸、墨、编辑台 | 夜、灯、展柜 |
| 第一眼印象 | 安静、耐看、像文档 | 有气派、夜里更漂亮 |
| 最适合 | 读长文、看作品、认真浏览 | 首页展示、分享给别人、深夜看 |
| 最容易翻车 | 平淡到没有记忆点 | 金一多就俗 |

## 技术上其实很轻

做法不是写两套页面，而是在 `</body>` 前追加一层独立的覆盖样式表，所有可调的东西收在 `:root` 里：

```css
:root{
  --ink:#0a0907;      /* 底色 */
  --paper:#f5f2ec;    /* 文字 */
  --gold:#c9a45c;     /* 主金 */
  --gold-2:#e8cf96;   /* 提亮金 */
}
```

原来的 DOM、脚本、路由、播放器、灯箱、双语、SEO 逻辑一行没改。所以两版的功能完全对等，也不存在"某一版少了什么"的问题。

好处是：想加第三版（比如冷灰、赭石、雾蓝），只需要复制一份文件，改十几个变量。坏处是：覆盖层会越来越长，将来如果真要长期维护多主题，应该把它抽成 CSS 变量文件 + `data-theme` 切换，而不是靠复制 HTML。这一步我留着，等真的需要第三版再说。

## 该选哪个

如果只能留一个，我选墨白。它更接近这个站的本意：记录，而不是展示。

但我不打算删掉黑金。它的存在提醒我一件事——**同一副骨架，换一层光，读起来就是另一个故事。** 颜色是最后一步，不是第一步。骨架立住了，颜色才只是气口；骨架没立住，再贵的金也只是在遮丑。
