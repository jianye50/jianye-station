#  鉴业の小站 · 项目配置（projects.txt）
#  首页和「关于」页的项目板块都在这里改，改完保存、刷新页面即可生效，
#  不用动 index.html。
#
#  书写规则：
#  · 每行一个项目，字段用 | 隔开；行首带 # 的是注释，不生效
#  · 内容里不要出现 | 字符
#  · 文件必须是 UTF-8 编码（记事本 / VS Code 默认就是）
#
#  每行格式（图标、颜色可省略，省略时用默认值）：
#  项目|中文名|英文名|中文描述|英文描述|网址|图标emoji|渐变色
#
#  · 网址建议用根相对路径（如 /os），换域名不用改配置
#  · 渐变色写 CSS 渐变，如 linear-gradient(135deg,#5b8cff,#3a4fd6)
# ============================================================
