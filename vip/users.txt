# ==================== 用户配置文件使用说明 ====================
# 1) 本文件一行就是一个用户，格式固定为：
#        用户名|密文
# 2) 用户名：用户登录时输入的名称
# 3) 密文：必须用 hash.html 页面生成，绝对不要手动编写或修改
# 4) 密文里已加密保存了「VIP状态 / 到期时间 / 备注」三项信息，
#    所以本文件不需要也不允许再单独写 VIP 等字段
# 5) 以 # 开头的行是注释，程序会自动跳过
# 6) 修改任一信息（密码 / VIP / 到期时间 / 备注）都必须重新生成一整行，
#    用新生成的行替换旧行
# 7) 本文件必须和 index.html、hash.html 放在同一个目录
# ================================================================
