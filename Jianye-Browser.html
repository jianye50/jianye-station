Core Features

为日常浏览打磨的核心功能

从标签管理到收藏、历史与下载，桌面浏览器该有的能力一应俱全，并围绕 Fluent 交互规范做了细致的体验打磨。

多标签页管理

标签内嵌于标题栏，支持拖动排序、中键关闭、双击空白处新建；弹出窗口自动接管为新标签页并前台切换。

智能地址栏

自动识别输入内容是网址还是关键词：合法地址直达访问，其余交由默认搜索引擎检索，搜索引擎可自定义。

收藏夹管理

一键收藏与取消，支持导入 / 导出 Netscape 书签 HTML 与 JSON，兼容 Chrome、Edge、Firefox，重复条目自动去重。

浏览历史记录

按日期分组展示，支持关键词检索；同一地址连续访问自动合并更新时间戳，默认最多保留 1000 条。

下载中心

独立下载面板展示实时进度与状态，可随时取消任务；下载历史本地留存，最多记录 200 条。

三态主题跟随

支持跟随系统、浅色、深色三种模式；系统切换深浅色时自动感知并同步界面与网页底色，DevTools 一并跟随。

页面缩放调节

放大、缩小、一键重置 100%，缩放因子随配置持久保存，下次启动自动恢复到上次的阅读比例。

开发者工具

内置 Chromium 开发者工具，快捷键唤起；右键菜单支持在新标签页打开链接，方便调试与浏览。

本地配置持久化

主页、搜索引擎、缩放比例等偏好写入本地配置文件；收藏、历史、下载各自独立存储，结构清晰易管理。

Fluent Design

完整对齐 WinUI 3 设计规范

界面从窗口边框到控件圆角、图标与排版层级，均遵循 Microsoft Store 应用的 Fluent 设计语言。

01

无边框沉浸式窗口

自定义标题栏承载标签页，Edge / Store 应用同款布局；标题栏双击最大化，窗口边缘可拖拽缩放。

02

Win11 原生圆角与边框

通过 DWM 窗口属性套用原生圆角与沉浸式深色边框，Win10 自动回退对应效果，视觉贴合系统。

03

Fluent 图标与字体层级

Segoe Fluent Icons 矢量图标（Win10 回退 MDL2 Assets），Segoe UI Variable 字体，14px 正文 / 12px 说明排版层级。

04

分层颜色令牌体系

Layer / Card / ControlFill / Text / Stroke / Accent 分层取色，控件 4px 圆角、浮出层 8px 圆角，规范统一。

数据留在本地。收藏夹、浏览历史与下载记录均以 JSON 文件保存在本机用户目录（~/.jianye_browser），不强制联网、不上传个人浏览数据；书签可随时通过标准 HTML 格式导出迁移到其他浏览器。
