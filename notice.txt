# ============================================================
#  公告配置文件（notice.txt）
#  每行一条公告，字段用 | 隔开；# 开头的行是注释，不参与解析。
#  这个文件和 profile.txt 完全独立，改公告只动这里。
#
#  支持两种公告：
#
#  1) 首次公告 —— 用户第一次进站时弹出，点了「知道了」之后
#     永远不再弹（记录存在用户浏览器里，换浏览器/清缓存会再看一次）
#
#  2) 普通公告 —— 只要用户没确认过，不管什么时候进站都会弹；
#     确认后不再弹。可配多条，弹窗里会分区一起展示。
#     以后想发新公告：直接改某一行的标题或内容即可，
#     内容变了会自动当作"新公告"，老访客会再收到一次弹窗。
#
#  写法格式（统一双语：中文标题 + 英文标题 + 中文内容 + 英文内容）：
#    首次公告|中文标题|英文标题|中文内容|英文内容
#    公告|日期|中文标题|英文标题|中文内容|英文内容
#
#  日期写法：2026-11-17 或 2026-11-17 15:35:39（以「公告」开头、
#  第一个字段长得像 YYYY-MM-DD 开头就自动当作日期）。
#  历史公告板块（关于页最底部）按这个日期倒序展示，没写日期的排在最后。
#
#  注意：
#  · 配置按行解析，内容里想换行就写字面量 \n（渲染时会变成真正的换行）
#  · 删掉某一行 = 撤下那条公告
#  · 下面所有示例都是注释状态（行首带 #），去掉行首的 "# " 即可启用
# ============================================================
